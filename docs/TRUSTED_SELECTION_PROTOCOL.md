# 可信分类与选股辅助准入协议

这个项目先验证“波段分类是否可信”，再验证“这些概率是否提供独立的横截面信息”。两层必须隔离；任何一层失败，都只保留为研究与人工审核工具。

## 第一层：分类可信度

1. 人工真值使用按年份、股票、行业、市场状态分层的随机样本，UNKNOWN 富集但保存入样概率；评估时做逆概率加权。
2. 使用全市场统一日历的 purged walk-forward。训练、校准、测试在全局时间上严格分离，阈值只在校准集选择。
3. 同时报告闭集 F1/Brier/LogLoss 和选择性指标：ECE、覆盖率、选择性风险、真实 UNKNOWN 拒绝率、Coverage–Risk 曲线。
4. 默认研究准入要求：选择性风险不高于 10%，ECE 不高于 10%，覆盖率不低于 50%，真实 UNKNOWN 拒绝率不低于 50%。这些阈值必须在新留出集揭盲前冻结。
5. 还需按年份、行业、波动制度、多周期冲突和边界稳定度分层；总体均值通过但任一关键子群崩溃，仍不得进入第二层。

## 第二层：只做选股辅助检验

分类层只向第二层提供当时可得的软概率、熵、UNKNOWN、边界稳定度和上下文；不得提供离线 HSMM 标签、未来边界、未来收益或事后修订字段。目标收益按共同市场交易日定义，缺少第 `t+h` 日记录不延长持有期，可交易性未知默认剔除。

每个预先指定期限使用严格扩展窗 OOS 分数，并与动量、反转、波动、规模和行业基线做同样本增量比较。`evaluate_incremental_features` 在完全相同的公共 OOS 行上配对比较“经典基线”与“基线 + 波段概率”，并对逐日 Rank IC 差值计算 HAC t 值，避免拿两个不同样本的总体 IC 做伪增量比较。默认研究准入同时要求：

- Rank IC 为正且 HAC t 值至少 2.0；
- 日度 IC 为正比例至少 55%；
- 分组收益单调性至少 0.5；
- 扣除换手成本和滑点后的多空均值为正；
- 至少 1,000 个真正 OOS 评分样本，因果审计通过；
- 跨年度、行业和市场状态方向稳定，并在完全独立的新时期复现。

`assess_selection_evidence` 会机械执行上述核心门槛。通过只表示“值得进入更大的独立测试”，不表示可预测、可交易或可自动下单。

## 当前结论

现有 8 股、2021–2024 试验未通过：5/20/60 日 Rank IC 的 HAC t 值分别约为 1.04、0.36、1.55，且 20/60 日分组单调性为负。当前系统的价值是波段发现、概率化描述、UNKNOWN 优先审核和研究样本组织；尚无可信证据证明可辅助选股。
